\# ☁️ Cloud Security Monitor



Projeto desenvolvido para estudar e aplicar conceitos de \*\*Cloud Computing, monitoramento, redes e segurança da informação\*\* utilizando Python.



O Cloud Security Monitor realiza verificações de disponibilidade de um serviço, registra informações em logs, acompanha métricas e disponibiliza os dados através de uma API e de um dashboard web.



\---



\## 🎯 Objetivo



O objetivo do projeto é construir, passo a passo, uma ferramenta de monitoramento capaz de:



\- Verificar a disponibilidade de uma URL

\- Identificar falhas de comunicação

\- Medir o tempo de resposta

\- Registrar eventos em logs

\- Contabilizar falhas consecutivas

\- Identificar estados de atenção e criticidade

\- Calcular métricas de disponibilidade

\- Disponibilizar informações através de uma API

\- Exibir informações em um dashboard web
